Hello World to I/O

01 A First Taste of Java

Why "Hello World" exists

Popularized by Brian Kernighan and Dennis Ritchie, it helps beginners get past the first hurdles of a language — writing, compiling, and running a program.

Python:

print("Hello World")

Java:

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}

Core philosophy of Java

Java is fully object-oriented — everything revolves around classes and objects, and functions cannot exist independently. This encourages modularity, organization, data protection, and reusable code.

Key idea — a public interface for user access, and a private implementation for internal working.

Understanding the main function

public static void main(String[] args)
  • public — accessible everywhere; the JVM must be able to call it
  • static — runs without an object, avoiding a "catch-22" problem
  • void — returns nothing (Python equivalent: None)
  • String[] args — stores command-line arguments
java HelloWorld Hi
→ args[0] = "Hi"

Java syntax rules

  • Braces { } define blocks — classes, methods, loops
  • Semicolon ; terminates statements
  • Indentation is for readability only — the compiler ignores it

This differs from Python, which uses indentation itself to define blocks.

System.out.println()

System.out.println("Hello World");
  • System — a built-in class
  • out — the static output stream
  • println() — prints and adds a new line
  • print() — prints on the same line

Java compilation process

Java's motto is "Write Once, Run Anywhere." The JVM — an abstract machine that runs Java programs — converts bytecode into machine instructions, so the same code runs unchanged on Windows, Linux, and macOS.

Source Code (.java)↓Compile using javac↓Bytecode (.class)↓JVM Executes↓Output on Screen

Compilation steps

  1. Write source code → HelloWorld.java
  2. Compile → javac HelloWorld.java → produces HelloWorld.class
  3. The .class file contains bytecode
  4. Run → java HelloWorld → the JVM executes the bytecode

File naming rule — the filename must match the class name: public class HelloWorld must live in HelloWorld.java.

Automatic dependency management — the compiler auto-compiles dependent classes, so compiling A.java may also compile B.java if it's used.

  • Java's "Hello World" looks lengthy because Java strictly follows object-oriented design, explicit syntax rules, and platform-independent execution through the JVM.

02 Basic Datatypes in Java

Java's design philosophy

Java is designed mainly as an OOP language, but includes primitive types for simplicity and performance — easier for programmers coming from C/C++, faster memory operations, simpler arithmetic.

Platform independence — data type sizes are fixed by the JVM, so behavior is identical on every system. int is always 4 bytes in Java, unlike C/C++ where size can depend on hardware or compiler.

Primitive scalar types

Java has 8 primitive data types.

Integer types

TypeSizePurpose
byte1 byteSmall integers
short2 bytesMedium integers
int4 bytesStandard integer
long8 bytesVery large integers
 
int age = 20;
long population = 8000000000L;   // use L suffix

Floating-point types

TypeSizePurpose
float4 bytesDecimal numbers
double8 bytesMore precision

Decimal literals default to double:

float x = 3.14f;   // use f suffix

Character and boolean types

char is 2 bytes (Unicode) and supports global languages:

char c = 'A';
String s = "Hello";
char pi = '\u03C0';   // π

boolean is 1 byte, with values true and false (lowercase only).

Variables, declarations & constants

Declaration syntax: type variableName;. Multiple variables can share a line:

int x, y, z;

Constants use final — reassigning one is a compilation error:

final float PI = 3.14f;

Operators & arithmetic

OperatorMeaning
+Addition
-Subtraction
*Multiplication
/Division
%Modulus

Integer division truncates decimals; 10 % 3 gives 1.

Shortcut operators — ++, --, +=, -=, *=:

x++;
x += 5;

There's no exponent operator — use Math.pow(a, n):

Math.pow(2, 3);   // 8.0

Type conversion widens automatically:

int x = 5;
float y = x;   // int → float

Strings in Java

Strings are objects, not primitives, and are immutable — modifying one creates a new string:

String s = "cat";
s = "b" + s.substring(1);   // "bat"

Unused strings are removed automatically by garbage collection. Length: s.length().

Arrays in Java

Arrays store multiple values of the same type, at a fixed size.

int[] a;                 // declaration
a = new int[5];           // allocation
int[] a = new int[5];     // combined

int n = 10;
int[] a = new int[n];     // dynamic size at runtime

int[] a = {2, 3, 5, 7};   // initialization

Size is fixed once created. Indexing starts at 0, last index is length - 1. Length is a field, not a method: a.length (no parentheses).

Documentation — Java evolves continuously; Java 11 is stable and widely used in teaching and industry, with official docs maintained by Oracle.

03 Control Flow in Java

General structure & syntax

PythonJava
Indentation defines blocksBraces {} define blocks
No semicolonsSemicolons end statements
Uses def for functionsFunctions are methods inside classes

Every statement must end with ;, and braces define blocks — optional for a single statement, but best practice is to always use them.

Functions in Java are called methods:

public static int add(int a, int b) {
    return a + b;
}

public — accessible everywhere · static — runs without an object · int — return type · void — no return value.

Conditional execution

if (x > 0) {
    System.out.println("Positive");
} else {
    System.out.println("Negative");
}

Multi-way branching uses else if, not elif:

if (x > 0) {
    System.out.println("Positive");
} else if (x < 0) {
    System.out.println("Negative");
} else {
    System.out.println("Zero");
}

Conditions must always sit inside parentheses.

Conditional loops

while
  • Checks the condition before running
  • May never execute if false initially
do-while
  • Executes at least once
  • Common for input prompts, menus
int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}
int i = 0;
do {
    System.out.println(i);
    i++;
} while (i < 5);

Iteration (for loops)

Basic (C-style) for loop — initialization, condition, update:

for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

For-each loop — traverses arrays/collections, taking each value in turn:

int[] arr = {1, 2, 3};
for (int v : arr) {
    System.out.println(v);
}

Local scoping

Variables exist only inside their declared block — i in a for loop exists only inside that loop, preventing accidental interference. A for-each loop's variable declaration is mandatory and local.

The switch statement

switch (value) {
    case option1:
        // code
        break;
    case option2:
        // code
        break;
    default:
        // code
}
int day = 2;
switch (day) {
    case 1: System.out.println("Monday"); break;
    case 2: System.out.println("Tuesday"); break;
    default: System.out.println("Invalid");
}

Fall-through — without break, execution continues into the next case:

case 1: System.out.println("One");
case 2: System.out.println("Two");
// case 1 matching prints:
// One
// Two

break in loops

break exits a loop immediately, and supports labeled breaks for nested loops:

outer:
for (...) {
    for (...) {
        break outer;
    }
}

Strict return rules

Non-void functions must return the correct type — a missing return is a compiler error:

public static int add(int a, int b) {
    return a + b;
}

Void functions return nothing:

public static void hello() {
    System.out.println("Hello");
}

04 Defining Classes & Objects in Java

What is a class?

A blueprint/template that defines data (variables) and behavior (methods):

public class Car {
    String color;
    void drive() {
        System.out.println("Car is moving");
    }
}

color is data; drive() is behavior.

What is an object?

A real instance of a class:

Car c = new Car();

Class = blueprint, object = actual instance — each object holds its own separate data:

Car c1 = new Car();
Car c2 = new Car();   // c1 and c2 store separate values

File naming rule — the public class name must match the file name exactly (public class Date → Date.java); Java is case-sensitive.

Instance variables & visibility

Instance variables are declared inside a class but outside any method:

class Student {
    int age;
}
  • private — accessible only inside the same class
  • public — accessible everywhere
  • default (package-private) — accessible inside the same package
Encapsulation — keep variables private, and use methods to access them.

Interacting with objects

Declaring a variable does not create an object:

Date d;              // only a reference
Date d = new Date(); // actual object

Getter (accessor) returns a value; setter (mutator) updates one:

public int getAge() { return age; }
public void setAge(int a) { age = a; }

The this keyword

this refers to the current object — useful when a parameter shares a name with an instance variable:

public void setAge(int age) {
    this.age = age;   // this.age is the field, age is the parameter
}

Constructors

A constructor is a special method that initializes an object — same name as the class, no return type, and runs automatically with new:

class Student {
    int age;
    Student() { age = 18; }
}
Student s = new Student();

Constructor overloading

class Student {
    Student() {}
    Student(int age) {}
}

Constructor chaining

class Student {
    int age;
    Student() { this(18); }
    Student(int age) { this.age = age; }
}

Default constructor

Auto-created if none is written, giving defaults — int → 0, float → 0.0, boolean → false, object → null. Defining any constructor removes Java's automatic default.

Object copying

Simple assignment makes both references point to the same object:

d2 = d1;

A copy constructor creates a genuinely separate object with the same values:

class Student {
    int age;
    Student(Student s) { this.age = s.age; }
}
Student s2 = new Student(s1);
Private access nuance — objects of the same class can access each other's private variables.

05 Basic Input & Output in Java

Introduction to Java I/O

I/O covers input (data into the program) and output (data out of it). The System class is Java's built-in class for I/O operations. System.out displays output — think of it as a pipe to the monitor. System.in receives input — a pipe from the keyboard.

Input mechanisms

Java provides two main input classes: Console and Scanner.

A. Console class

Similar to Python's input():

Console c = System.console();
String name = c.readLine("Enter name: ");
char[] pass = c.readPassword("Enter password: ");
MethodReturns
readLine()String
readPassword()char[]

readPassword() returns a char[] rather than a String because it's more secure — its contents can be erased manually. Good for simple text and password input; limited for parsing integers.

B. Scanner class

More flexible input handling:

import java.util.Scanner;
Scanner sc = new Scanner(System.in);
MethodPurpose
nextInt()Integer
nextDouble()Decimal
next()Single word
nextLine()Full line
 
System.out.print("Enter age: ");
int age = sc.nextInt();
System.out.println(age);

Advantage — parses integers, doubles, strings, and booleans directly. Limitation — cannot hide passwords.

Output mechanisms

A. System.out.println()

Prints and moves to the next line:

System.out.println("Hello");
System.out.println("Java");
// Hello
// Java

B. System.out.print()

Prints on the same line:

System.out.print("Hello ");
System.out.print("Java");
// Hello Java

C. System.out.printf()

Formatted printing, borrowed from C — controls spacing, decimal places, style:

double pi = 3.14159;
System.out.printf("%.2f", pi);   // 3.14
SpecifierMeaning
%dInteger

%sString
%cCharacter

System.out.printf("%5d", 25);     // reserves 5 spaces
System.out.printf("%.3f", 3.14159); // 3.142

Similar in spirit to Python's % formatting style.
