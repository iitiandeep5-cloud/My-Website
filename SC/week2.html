Lecture 1: Command Line Editors — Part 01

Introduction to Command Line Editors

  • Definition: tools to edit files directly inside the terminal.
  • Use cases: remote servers, supercomputers, systems with slow/no graphical interface.
  • Advantages: faster than download/upload cycles; lightweight and efficient; work in low-bandwidth environments; available on almost all Unix/Linux systems.

Classes of Editors

A. Line Editors

  • Examples: ed, ex.
  • Edit one line at a time; very lightweight; universally available.

B. Terminal (Visual) Editors

  • nano — beginner-friendly, derived from pico; shortcuts displayed on screen.
  • vi — most popular Linux terminal editor; powerful but complex; extremely efficient once mastered.
  • emacs — alternative to vi; highly customizable.
Note: vi and nano are usually installed by default in Linux.

C. GUI Editors

  • Examples: gedit (GNOME), kwrite (KDE).
  • Similar to Windows Notepad.

D. Specialized Programmer Editors

  • Examples: Sublime Text, Atom, Brackets (HTML-focused).

E. IDEs

  • Full development suites with editor, compiler, debugger.
  • Examples: Eclipse, NetBeans, Bluefish.

Essential Features of an Editor

  • Navigation: scroll, page movement, line numbers.
  • Search: keywords, regex.
  • Editing actions: insert, replace, delete, cut/copy/paste.
  • Code awareness: syntax highlighting.
  • Advanced features: key mapping, init scripts, macros, plugins.

Deep Dive: ed Line Editor

  • Definition: oldest Unix text editor, line-by-line.
  • Importance: foundation for many vi commands; useful in emergency terminal situations; available almost everywhere.

Core Characteristics

  • Non-visual, no default prompt (enable with P).
  • File opening shows bytes loaded.

Address Selection

General format: [start],[end][command]

SymbolMeaning

Common Commands

  • p — Print: display lines.
  • a — Append: add text after current line.
  • d — Delete: remove lines.
  • s — Substitute: regex replacement, e.g. s/old/new/; backreference: s/(word)/<\1>/.
  • j — Join: merge lines.
  • m — Move: relocate lines.
  • u — Undo: revert last action.
  • w — Write: save file.
  • q — Quit: exit editor.
  • f — File Name: show filename.
  • r — Read: insert another file/shell output.
  • ! — Shell Escape: run shell commands.

Lecture 2: Command Line Editors — Part 02

Nano and Pico Editors

Relationship Between Pico and Nano

  • In many Linux systems, pico is linked to nano.
  • nano = improved, modern version of pico.
  • Check actual file: readlink -f /usr/bin/pico
  • Purpose of readlink: resolves symbolic links, shows actual executable path.

Features of Nano Editor

  • Visual Interface — easy-to-use, cursor-based editor; syntax highlighting with colors for comments, loops, keywords, active lines.
  • Beginner Friendly — similar to Windows Notepad; arrow keys for navigation; direct typing for text entry.

Important Nano Commands

ShortcutFunction
Ctrl + OSave file
Ctrl + XExit editor
Ctrl + SSave file
Ctrl + RInsert another file
Ctrl + Q / Alt + QSearch & replace
Alt + NToggle line numbers
  • Save file: Ctrl + O; exit nano: Ctrl + X (prompts to save if changes are unsaved).
  • Read another file — insert file content: Ctrl + R (adds another file's contents at cursor position).
  • Search text: Ctrl + Q or Alt + Q; navigation is character-wise, word-wise, line-wise, page-wise.
  • Line numbers: toggle with Alt + N — useful for coding, debugging, error tracking.

Vi (Visual) Editor

  • Powerful terminal editor, standard in Unix/Linux.
  • Improved version: Vim.
  • Available on almost all operating systems.

A. Three Major Modes of Vi

  • Command Mode — default mode when file opens; used for navigation, commands, copy/delete/search; return with Esc.
  • Insert Mode — used to type/edit text; enter with i (insert at cursor), a (append after cursor), o (open new line); screen shows -- INSERT --.
  • Ex Mode (Colon Mode) — access with :; used for save, quit, search, replace.

  • Example: :%s/hello/hola/g → replace in entire file.

Lecture 3: Command Line Editors — Part 03

Environment Setup & File Management

Secure Copy (scp)

  • Purpose: transfer files securely between remote and local systems.
scp username@IP:/path/file .
  • Requirements: remote IP, file path, username, password.
  • Use case: copy files from remote Linux servers, supercomputers, cloud systems.

Archive Management (tar)

Extract tar files:

tar -xvf filename.tar
  • Purpose: unpack archived directories/files.

DOS vs Linux File Format

  • Problem: Windows files may contain ^M at line ends.
  • Cause: Windows → Carriage Return + Line Feed; Linux → Line Feed only.
  • Symbol: ^M = Control-M = Carriage Return.

Nano (Pico) Editor

  • Simple terminal text editor.
  • Beginner-friendly, similar to Windows Notepad.

Features

  • Arrow key navigation.
  • Syntax highlighting.
  • Easy editing directly in terminal.

Important Nano Commands

  • Best for large files, fast editing, source code, log files.

Search, Replace & Regex in Vi

  • Forward search: /word; next match: n.
  • Global replacement: :%s/old/new/g

Removing ^M Characters

  • Capture control characters: press Ctrl + V then Ctrl + M.
  • Use in replacement commands to remove DOS formatting.

Regular Expressions (Regex)

  • Purpose: advanced searching, massive editing, pattern matching.
  • Escaping special characters: e.g. \[ treats [ as normal text.

Emacs Editor

  • Professional, powerful editor.
  • Unlike Vi, uses only one mode; normal typing inserts text directly.
  • Commands use C- = Ctrl key, M- = Meta/Alt key.

Launch Emacs in Terminal

emacs -nw
  • -nw = no window mode (runs inside terminal).

Lecture 4: Network Basics

Network Basics

  • Structure: Private Network → ISP → Internet.
  • Examples: Home Wi-Fi, College LAN → ISP → Public Internet.

Types of Networks

  • Private Network: internal use, secure, not internet-visible.
  • Public Network: internet-facing, globally accessible.

IP Addressing (IPv4)

What is an IP Address?

  • Unique identifier for devices on a network.
  • Enables communication.

Localhost Address

  • 127.0.0.1 → loopback, system talks to itself.
  • Used for testing/local services.

Private IP Addresses

  • Not visible on public internet.
  • Ignored by routers.
  • Used inside local networks.

Classes of Private IPs

ClassRangeFeaturesExample Use
A10.x.x.x~16 million addressesLarge universities/orgs
B172.16.x.x → 172.31.x.x~1 million addressesMedium orgs
C192.168.x.xSmall/home networksMost common

Public IP Addresses

  • Any IP outside private ranges.
  • Used for websites, public servers, online services.

Network Hierarchy

  • Nested private networks for extra security.
  • Examples: HPC clusters, storage servers, research labs.

Network Ports & Services

What is a Port?

  • Service counter for network communication.
  • Each port = specific service.

Important Port Numbers

PortService
21FTP
22SSH
25SMTP Mail
80HTTP
443HTTPS
631Linux Printing (CUPS)

  • FTP (21): file transfer.
  • SSH (22): secure remote login, command execution.
  • HTTP (80): unsecured web traffic.
  • HTTPS (443): secure encrypted traffic.

Remote Access Methods

  • VPN: connect remotely to private networks.
  • SSH Tunneling: secure encrypted communication, multiple hops, port forwarding.
  • Remote Desktop Tools: GUI-based access — examples: X2Go, RDP, Apache Guacamole.
  • Commercial Tools: TeamViewer, AnyDesk, Zoho Assist.

Network Security & Firewalls

Firewalls

  • Block unauthorized access.
  • Functions: filter traffic, control ports, prevent attacks.

Types

  • Machine-level firewall → protects individual systems.
  • Network firewall → protects entire networks.
  • Web Application Firewall (WAF) → protects websites (blocks SQL injection, malicious HTTP).

SELinux

  • Advanced Linux security layer.
  • Features: Role-Based Access Control (RBAC); sandboxing (restricts processes).

Check SELinux Status

  • File context: ls -lZ
  • Process context: ps -eZ

Essential Networking Commands

  • ifconfig → shows interfaces, local IPs.
  • ping → check connectivity.
  • traceroute → show packet hops.
  • nslookup / dig → hostname ↔ IP conversion.
  • netstat → active connections, open ports.

Advanced Tools

  • nmap → port scanning.
  • wireshark → packet analysis/sniffing (with permission).

High-Performance Computing (HPC) & Linux

Linux in Supercomputers

  • All Top 500 supercomputers run Linux.

Remote Processing Workflow

  • SSH into supercomputer.
  • Process data remotely.
  • Download only results (datasets too large to transfer).

Job Schedulers

  • Users submit jobs instead of direct execution.
  • Example: qstat.
  • Scheduler handles queues, resources, policies.
