Lecture 1: $hell Variables

Shell Variables (Basic Idea)

  • Temporary memory locations used to store data.
  • Faster than file storage (no disk I/O).
  • More secure (stay inside shell and child processes).
  • Usage: Store configuration values, usernames, paths, ports.
  • Exist only during the shell session unless permanently configured.

Displaying Variables

echo $VARIABLE_NAME
echo $USER
echo $HOME
echo $PWD
  • $ tells the shell to replace with stored value.

Common Shell Variables

VariableMeaning
$USERCurrent logged-in user
$HOMEUser's home directory
$HOSTNAMEComputer/Server name
$PWDPresent Working Directory

echo Command

Prints text or variable values.

echo Hello
echo "Hello World"
  • Without quotes → multiple spaces collapse.
  • With quotes → spaces preserved.

pwd vs $PWD

Aspectpwd (Command)$PWD (Variable)
ExecutionRuns programReads stored value
SpeedSlightly slowerFaster
OutputPrints directoryStores string value

Quotation Marks

  • Double Quotes " " → Expand variables.
    Example: echo "User is $USER" → User is student
  • Single Quotes ' ' → Literal text.
    Example: echo 'User is $USER' → User is $USER

Multi-line Input

  • If quotes aren't closed, shell shows > prompt.
  • Waits for closing quote before execution.

Escape Character

  • Backslash \ removes special meaning.
echo \$USER   # Output: $USER

Environment Discovery Commands

CommandShows
printenvExported variables
envExported variables
setVariables + Functions (long output)

PATH Variable

  • Stores directories where shell searches for commands.
  • Example: /usr/bin:/bin:/usr/local/bin
  • Search order: left → right.
  • Security: Malicious executables earlier in PATH override safe ones.

Aliases

Shortcut for commands.

  • Example: alias ll='ls -l'
  • Bypass alias:
    1. \command
    2. /usr/bin/command
    3. ./command

Special Shell Variables

  • $0 → Current shell name.
  • $$ → Current shell PID.
  • $? → Exit status of previous command.
  • $- → Active shell options.

Exit Codes

  • Range: 0–255
  • Important Codes:
    • 0 → Success
    • 1 → General Error
    • 126 → Command not executable
    • 127 → Command not found
    • 130 → Interrupted (Ctrl+C)
    • 137 → Killed (kill -9)

Modulo 256 Rule

  • Exit codes are 1 byte.
  • Larger values reduced by % 256.
  • Example: 256 → 0 (appears as success).

Shell Flags ($-)

  • View with echo $-
  • Common flags: h (hashing), B (brace expansion), i (interactive), m (job control), H (history enabled)

Flag Details

  • h: Remembers command locations → faster execution.
  • B: Brace expansion. Example: {a,b}{1,2} → a1 a2 b1 b2
  • i: Interactive mode.
  • m: Job control (background/foreground jobs).
  • H: History shortcuts (e.g., !!).

Process Monitoring Commands

  • ps → Snapshot of processes.
  • top → Live monitoring (CPU, RAM).
  • jobs → Background jobs.
  • kill PID → Terminate process.

Process Tree: ps --forest → Shows parent-child relationship.

PID and PPID

  • PID: Unique process ID.
  • PPID: Parent process ID (who created it).

Root Process

  • Ancestor of all processes: init or systemd. Always PID = 1.

Revision

  • Shell variables → Temporary memory storage.
  • echo $VAR → Display variable.
  • $USER, $HOME, $PWD → Common variables.
  • pwd vs $PWD → Command vs variable.
  • Quotes: " " expand, ' ' literal.
  • \ → Escape character.
  • printenv, env, set → Environment discovery.
  • $0, $$, $?, $- → Special variables.
  • Exit codes: 0 success, non-zero error.
  • PATH → Command search directories.
  • Aliases → Shortcuts.
  • Process monitoring: ps, top, jobs, kill.
  • Process tree: ps --forest.
  • PID, PPID, Root process (PID=1).

Lecture 2: Shell Variables — Part 1

Variable Initialization

variable=value
name=Deepika
age=20
student_name=Rahul
marks1=95
total_marks=500
  • Allowed: Letters, numbers, underscore (_).
  • Cannot start with a number (10name=Rahul → error).
  • No spaces around = (name = Rahul → error).
  • Use underscore instead of space (Student_Name=Rahul).

Assigning Values

  • Numbers: age=20 (no quotes needed).
  • Strings: name=Rahul (works for one word).
  • Strings with spaces: Must use quotes.
city="New Delhi"

Clearing Variables

  • Method 1 (unset): Removes variable completely. unset name
  • Method 2 (null assignment): Keeps variable but empties value. name=
  • Difference: unset → deletes variable; var= → variable exists but empty.

Command Substitution

today=`date`     # old syntax
today=$(date)    # modern syntax

Variable Scope

myvar=100

Export Variables: Make variable available to child processes.

export myvar
export myvar=100

Parent and Child Shell

  • Parent exports variable → child can access.
  • Child changes never affect parent.
  • Rule: Parent ➜ Child ✅ | Child ➜ Parent ❌

Testing Variables

test -v myvar
[ -v myvar ]
  • Return status: echo $? → 0 if exists, 1 if not.
  • Check empty string: [ -z "$name" ]

Return Status ($?)

  • Every command updates $?.
  • 0 → Success / True | 1 → Failure / False

Parameter Expansion

SyntaxMeaning
${city:-Delhi}Default Value (use if unset, don't assign)
${city:=Delhi}Set Default (assign if unset)
${var:?Variable Missing}Error Message if unset
${var:+YES}Alternative Value if set

Variable Discovery

echo ${!H*}
# Example output: HOME HOSTNAME HISTFILE

String Operations

  • Length: echo ${#name}
  • Substring: echo ${name:0:4} → Deep, echo ${name: -2} → ha
  • Remove Prefix: ${var#pattern} (shortest), ${var##pattern} (longest)
  • Remove Suffix: ${var%pattern} (shortest), ${var%%pattern} (longest)
  • Search & Replace:
    • ${var/old/new} — first occurrence
    • ${var//old/new} — all occurrences
    • ${var/#old/new} — beginning
    • ${var/%old/new} — end

Case Conversion

  • Lowercase: first letter ${var,}, entire string ${var,,}
  • Uppercase: first letter ${var^}, entire string ${var^^}

Variable Attributes (declare)

  • Integer: declare -i age
  • Lowercase: declare -l city
  • Uppercase: declare -u country
  • Read-only: declare -r PI=3.14

Remove Attributes

declare +i age
  • Exception: Read-only (-r) cannot be removed. Restart shell required.

Arrays

Indexed Arrays:

fruits=(Apple Mango Banana)
echo ${fruits[1]}   # Mango

Non-continuous indices allowed.

Associative Arrays:

declare -A student
student[name]=Rahul
student[age]=20
echo ${student[name]}   # Rahul

Array Operations

  • Access element → ${arr[index]}
  • All elements → ${arr[@]}
  • Number of elements → ${#arr[@]}
  • List all indices/keys → ${!arr[@]}
  • Delete element → unset arr[2]
  • Append (indexed only) → arr+=("Orange")

Revision

  • name=value → Variable syntax (no spaces).
  • Variable names → Letters, numbers, _; cannot start with number.
  • Strings with spaces → Use quotes.
  • unset var → Delete variable.
  • var= → Empty value but exists.
  • $(command) → Command substitution.
  • Variables local by default.
  • export var → Child processes can use.
  • Parent ➜ Child ✅ | Child ➜ Parent ❌.
  • test -v var → Exists check.
  • -z → Empty string check.
  • $? → Return status (0 success, 1 failure).
  • ${var:-x} → Use default only.
  • ${var:=x} → Set and use default.
  • ${var:?msg} → Error if unset.
  • ${var:+x} → Alternate if exists.
  • ${!H*} → Variables starting with H.
  • ${#var} → String length.
  • ${var:offset:length} → Substring.
  • ${var#pattern} / ${var%pattern} → Remove prefix/suffix.
  • ${var/old/new} → Replace.
  • ${var,,} / ${var^^} → Case conversion.
  • declare -i/-l/-u/-r → Attributes.
  • Arrays: ${arr[@]}, ${#arr[@]}, ${!arr[@]}.
  • += works only for indexed arrays.

Lecture 3: Shell Variables — Part 2

Shell Environment Inspection

  • Always check existing variables before scripting.
  • Helps avoid conflicts, verify required variables, and debug scripts.

Commands to View Environment Variables

printenv
printenv HOME
CommandPurpose
printenvShow exported environment vars
envShow exported environment vars

Variable Name Discovery

echo ${!prefix*}
echo ${!H*}    # HOME HOSTNAME HISTSIZE
echo ${!HI*}   # HISTSIZE
  • $HOME → Variable value
  • ${!H*} → Variable names starting with H

String Length

name=abcdef
echo ${#name}   # 6

String Slicing (Substring)

${var:offset:length}
text=abcdefgh12345678
echo ${text:3:3}   # def

Negative Offset

${var: -3:3}
text=abcdefgh12345678
echo ${text: -3:3}   # 678

Date Example

mydate=$(date)
echo ${mydate:0:3}   # Sun

Alternative:

date "+%d %B %Y"   # 22 January 2023

Prefix Removal (#)

  • Shortest: ${var#pattern}
  • Longest: ${var##pattern}
file=file.txt.jpg
echo ${file##*.}   # jpg

Suffix Removal (%)

  • Shortest: ${var%pattern}
  • Longest: ${var%%pattern}
file=file.txt.jpg
echo ${file%%.*}   # file

Filename Reconstruction

file=myfilename.somethingelse.jpg
echo ${file%%.*}.${file##*.}   # myfilename.jpg

Search and Replace

  • First match: ${var/old/new}
  • All matches: ${var//old/new}
  • Beginning only: ${var/#old/new}
  • End only: ${var/%old/new}

Case Conversion

  • Lowercase first letter: ${var,}
  • Lowercase all: ${var,,}
  • Uppercase first letter: ${var^}
  • Uppercase all: ${var^^}

declare Command

  • Assign attributes to variables.
  • Syntax: declare option variable
  • - adds attribute, + removes attribute.

Variable Attributes

  • Integer: declare -i age
  • Lowercase: declare -l city
  • Uppercase: declare -u country
  • Read-only: declare -r PI=3.14

Remove Attributes

declare +i age
  • Exception: Read-only (-r) cannot be removed. Only restarting shell clears it.

Arrays

Store multiple values in one variable.

Indexed Arrays (-a):

declare -a fruits
fruits[0]=Apple
fruits[1]=Mango
fruits[2]=Orange

Sparse arrays allowed: arr[100]=C

Associative Arrays (-A):

declare -A student
student["id"]="Amal"
student["new student"]="Bimal"

Array Assignment

  • Single element: arr[0]="Apple"
  • Multiple elements: arr=("Apple" "Mango" "Orange")
  • Append (indexed only): arr+=("Banana")

Array Access & Metadata

  • Specific element: ${arr[1]}
  • All elements: ${arr[@]}
  • Number of elements: ${#arr[@]}
  • All indices/keys: ${!arr[@]}
  • Delete element: unset arr[2]

Store Command Output in Array

myfiles=($(ls))
echo ${myfiles[0]}

Revision Cheat Sheet

  • printenv / env → Show exported variables.
  • ${!H*} → Variable names starting with H.
  • $HOME → Variable value.
  • ${#var} → String length.
  • ${var:offset:length} → Substring.
  • Negative offset requires space.
  • ${var#pattern} / ${var##pattern} → Remove prefix.
  • ${var%pattern} / ${var%%pattern} → Remove suffix.
  • ${var/old/new} → Replace first match.
  • ${var//old/new} → Replace all matches.
  • ${var/#old/new} → Replace beginning.
  • ${var/%old/new} → Replace end.
  • ${var,}, ${var,,} → Lowercase.
  • ${var^}, ${var^^} → Uppercase.
  • declare -i/-l/-u/-r → Attributes.
  • Indexed arrays (-a) → numeric indices.
  • Associative arrays (-A) → string keys.
  • ${arr[@]} → All elements.
  • ${#arr[@]} → Count.
  • ${!arr[@]} → Indices/keys.
  • unset arr[index] → Delete element.
  • myfiles=($(ls)) → Store command output in array.
