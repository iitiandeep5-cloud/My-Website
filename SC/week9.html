Lecture 1: AWK Programming — Part 1

Introduction

  • AWK is a command-line programming language for text processing, data extraction, log analysis, and ETL tasks.
  • Processes data one record (line) at a time → efficient for large files.
  • Named after creators: Alfred Aho, Weinberger, Kernighan.
  • Standardized under POSIX (IEEE 1003.1-2008).

Common Versions

  • awk → symbolic link to gawk in most Linux systems.
  • nawk → New AWK.
  • mawk → fast implementation.
  • gawk → GNU AWK.
  • For portability → use POSIX-compliant syntax.

Why Use AWK

  • Fast for text processing.
  • Works directly in shell pipelines.
  • No lengthy programs required.
  • Excellent for filtering, transforming, summarizing data.

Execution Model

  • Automatically opens files, reads input, splits records into fields, executes code, closes files.
  • Flow:
    • BEGIN → initialization.
    • Input records processed one by one.
    • Pattern-action blocks executed.
    • END → final processing.

Records and Fields

  • Record = one unit of input (default: one line). Controlled by RS (Record Separator).
  • Field = part of a record (default separator: space). Controlled by FS (Field Separator).

Example — Input → Alice 90 95
$1 = Alice, $2 = 90, $3 = 95.

Structure of an AWK Program

BEGIN { initialization }
pattern { action }
END { final processing }
  • BEGIN block → runs once before input.
  • Body block → runs for each record.
  • END block → runs once after all records.

Range Patterns

  • Syntax: /start/, /stop/ { action }
  • Processes records between two matches.

Command-line Options

  • -v → pass variables.
    Example: awk -v limit=50 '$2 > limit' file.txt
  • -f → read script from file.
    Example: awk -f script.awk file.txt

Operators

  • Arithmetic: + - * / %
  • Comparison: == != < > <= >=
  • Logical: && || !
  • Increment/Decrement: ++ --
  • Ternary: condition ? value1 : value2

Control Statements

  • if: if ($2 > 50) print $1
  • if-else: if ($2 >= 40) print "Pass"; else print "Fail"
  • for loop: for(i=1; i<=NF; i++) print $i
  • while loop:
while(i<=NF) {
    print $i
    i++
}

Built-in Functions

  • String Functions: length(), substr(), split(), gsub(), match()
  • Mathematical Functions: sin(), cos(), log(), exp(), sqrt()

Pattern Matching

  • Entire line: /error/ { print }
  • Field-specific: $1 ~ /^[0-9]+$/ { print $1 }

Regex Field Separator

BEGIN { FS="[.:;@-]" }

Splits using multiple delimiters → useful for logs, CSVs, phone numbers, emails.

Efficiency

  • Processes one record at a time → constant memory usage.
  • Works with very large files.
  • Ideal for streaming data.

Applications

  • Log analysis.
  • CSV processing.
  • Report generation.
  • Filtering records.
  • Counting events.
  • Totals and averages.
  • ETL pipelines.
  • Command-line data cleaning.

Revision

  • Record = line, Field = column.
  • RS controls records, FS controls fields.
  • BEGIN → before input, Body → each record, END → after input.
  • $0 = whole line, $1...$n = fields.
  • NF = number of fields, NR = total records.
  • -v passes variables, -f runs script files.
  • ~ performs regex matching.
  • FS can be regex.
  • x = $1 + 0 converts text to number.

Lecture 2: AWK Programming — Part 2

Associative Arrays

  • AWK arrays are associative (hash-based), unlike C arrays.
FeatureC ArrayAWK Associative Array
IndexInteger onlyString or integer
MemoryContiguousSparse allocation
IndexingFixedDynamic

Example:

a[1]=10
a[2]=20
a[100]=50

Stores only indices 1, 2, 100 → memory-efficient.

Operations

  • Assignment: array[index] = value
  • Iteration:
for(i in array) print i, array[i]
  • Deletion: delete array[index]

Control Flow and Loops

  • C-style for loop: for(i=1; i<=10; i++) print i
  • Associative array loop: for(key in array) print key, array[key]
  • while loop:
while(condition){ statements }

do-while loop:

do{ statements } while(condition)

if statement: if($2 > 50) print $1

Extracting Data from Unstructured Text

  • Use regex to filter valid records.

Roll Number Pattern

Regex: [A-Za-z][A-Za-z][0-9][0-9][A-Za-z][0-9][0-9][0-9]
Example: CS21A101

Typical Flow

  • BEGIN: initialize variables.
  • Action block: match regex, store fee, update total.
  • END: print report.

Modularity and Custom Functions

Function syntax:

function square(x){ return x*x }

Calling: { print square($1) }

External scripts: awk -f library.awk -f script.awk data.txt

BEGIN and END Behavior

  • BEGIN runs even if file empty.
  • END runs even if file empty.
  • Action block runs only if records exist.

Mathematical Constants

Example:

BEGIN{ pi = 4 * atan2(1,1); print pi }

Automatic Type Conversion

  • AWK converts strings ↔ numbers.
  • Trick: x = parameter + 0 → forces numeric conversion.

  • Speed: Generate 2M records → 3.2s

Apache Log Analytics

Example Log:

192.168.1.5 - - [11/Jan/2023:10:15:20 +0530] "GET /index.html HTTP/1.1" 200
  • Extract IP: { print $1 }
  • Extract date: { print substr($4,2,11) }

Performance: 500,000 lines in <0.4s.

Using getline

  • Reads input from files, commands, pipelines.
"date" | getline today
print today

Security Profiling

  • Count requests per IP: { count[$1]++ }
  • Report:
END{ for(ip in count) print ip, count[ip] }

Reverse DNS lookup:

cmd = "dig -x " ip
cmd | getline host
close(cmd)

Integration with Linux

  • Combine with sort, uniq, grep, cut, dig, date.
cat access.log | awk '{print $1}' | sort | uniq -c

Why AWK is Powerful

  • Associative arrays.
  • Sparse memory allocation.
  • Regex support.
  • Custom functions.
  • Command integration.
  • Extremely fast, low memory usage.
  • Available on all Linux/Unix systems.

Revision

  • Arrays: associative, sparse, delete removes elements.
  • Loops: for, for(i in array), while, do-while.
  • Regex: filter valid records.
  • Script flow: BEGIN → Action → END.
  • Functions: reusable with function name(args){}.
  • Type conversion: x = value + 0.
  • Performance: 2M+ records, low memory.
  • Log analysis: $1 → IP, substr() → date.
  • Linux integration: getline, pipelines, DNS lookup.
