Lecture 1: Launching a Linux Virtual Machine

Why Use Virtual Machines (VMs)?

  • Run Linux safely without altering Windows.
  • Keep Windows safe: no need to remove the pre-installed OS.
  • Avoid BIOS/UEFI issues: OEM restrictions may block dual boot.
  • Linux experience: provides near-native Linux usage inside Windows.

Requirements for Virtualization

A. Linux ISO File

  • Download a Linux OS image.
  • Recommended: Ubuntu 20.04 LTS (x86_64, Intel/AMD).

B. Hypervisor Software

  • Hypervisor: software to run VMs.
  • Common options: Oracle VirtualBox, VMware Workstation Player.

C. Hardware Requirements

  • Disk space: ~20 GB.
  • RAM: 4 GB minimum, 8 GB+ recommended.
  • VM allocation: ~2 GB (2048 MB).

Setting Up Linux Using Hypervisors

A. Oracle VirtualBox

  1. Download Windows Host version.
  2. Install as Administrator.
  3. Click New → name VM.
  4. Allocate RAM.
  5. Create 20 GB virtual disk.
  6. Attach Ubuntu ISO in settings.
  7. Start VM → Install Ubuntu.
  8. Follow installation instructions.
Note: "Erase Disk" erases only the virtual disk, not Windows.

B. VMware Workstation Player

  1. Download for non-commercial use.
  2. Install with default settings.
  3. Create New VM → select Ubuntu ISO.
  4. Enter username & password.
  5. VMware auto-configures settings.
  6. System reboots after installation.

Windows Subsystem for Linux (WSL)

  • Runs Linux directly inside Windows.
  • Installation: Open PowerShell (Admin) → Run wsl --install → Restart PC → Create Linux username & password.

Advantages

  • Official Microsoft support.
  • Lightweight, fast.
  • Can run alongside VMware/VirtualBox.

Cloud-Based Linux Environments

A. Replit.com

  • Create Bash project.
  • Kernel 5.11.
  • Home directory: /home/runner.

B. CoCalc.com

  • Create/start project.
  • Terminal environment.
  • Files stored in /home/user.
  • Project must be stopped manually.

Mobile Linux Environment: Termux

  • App: Termux (Fredrik Fornwall).
  • Lightweight terminal app.
  • Uses phone storage.
  • Runs on Linux kernel (e.g., v4.14).

Lecture 2: Command Line Environment

Introduction to CLI

  • Definition: CLI allows interaction with Linux by typing commands instead of using a graphical interface.
  • Why use CLI? Automation (commands can be scripted/scheduled) and better control (more flexibility, faster execution for advanced tasks).

Terminal Emulators

  • Terminal (Ubuntu/GNOME): tabs, fonts, colors.
  • xterm: lightweight, minimal customization.
  • Guake: drop-down terminal (F12 toggle).
  • Konsole: KDE desktop terminal.

Essential Linux Commands

  • pwd — show current directory (e.g., /home/user).
  • ls — list files/folders.
  • ps — show running processes.
  • uname — display OS info.
  • clear — clear screen (Ctrl+L).
  • exit — close session (Ctrl+D).

Command Anatomy & Help

  • Command prompt: shows username, computer name, current directory, ends with $.
  • Options: modify behavior (e.g., ls -a).
  • Arguments: target of the command (e.g., a filename).

Important ls Variations

  • ls -a — show all files, including hidden (. prefix).
  • ls -l — detailed info (permissions, size, owner, type).

Getting Help with man

  • man ls → manual page for ls.
  • man = manual.
  • Section 1 contains shell commands.

Linux File System Hierarchy (FHS)

  • Root directory /: top-most directory.
  • Path separator /: used in paths (e.g., /home/user/Documents).

Special Directory Symbols

  • . (dot) — current directory.
  • .. (double dot) — parent directory.

cd Command (Change Directory)

  • Move up one level: cd ..
  • Return to home: cd

Understanding File Types

ls -l → first character shows type.

  • Character Device: reads data character by character (e.g., keyboard).
  • Block Device: reads data in blocks (e.g., hard disk).

Logic Behind Linux Hierarchy

  • Shareable vs Non-Shareable: Shareable → /usr, Non-Shareable → /etc.
  • Static vs Variable: Static → program files; Variable → logs, emails, temp data.

Lecture 3: Simple Commands in Linux — Part 1

Command Line Environment

  • Terminal Emulator: application where commands are typed.
  • Shell: program that interprets and executes commands. Common shell in Ubuntu: bash.

Unix Philosophy

  • "No News is Good News" → successful commands often produce no output.
  • No error message = command worked.
Safety for beginners: most beginner commands are read-only (display info, no damage).

Directory Navigation & Shortcuts

SymbolMeaning
.Current directory
..Parent directory
~Home directory
-Previous directory
  • cd .. → parent directory.
  • cd ~ → home directory.
  • cd - → previous directory.

System Information Commands

  • date — show current date/time.
  • date -R — RFC 5322 format (emails).
  • cal — display calendar (e.g., cal august 1947).
  • ncal — alternative calendar style.
  • free — show memory usage.
  • free -h — human-readable memory info.

Memory Terms

  • Total → total RAM.
  • Used → RAM in use.
  • Free → available RAM.
  • Swap → disk space used when RAM is full.
  • groups — show user groups. Important: sudo group → admin privileges.
  • man — open help manual (e.g., man ls).
  • clear — clear screen (Ctrl+L).

File Listing & File Types

ls -l — detailed file info.

SymbolMeaning
-Regular file
dDirectory
lSymbolic link
cCharacter device
bBlock device
sSocket
pNamed pipe
  • ls -a → show hidden files.
  • ls -i → show inode numbers.

File Permissions & Ownership

Example: rwxr-xr-x

GroupMeaning
OwnerFile owner permissions
GroupGroup member permissions
OthersPermissions for everyone else
  • r → Read
  • w → Write
  • x → Execute

Directory permissions: x lets a user enter the directory with cd.

Numerical (Octal) Permissions

  • Values: r = 4, w = 2, x = 1.
  • Examples: 7 = rwx, 5 = r-x.
  • Common permission: 755 → Owner: rwx, Group: r-x, Others: r-x.

chmod Command

  • Remove group write: chmod g-w filename
  • Set numeric permission: chmod 700 filename

File Management Commands

  • mkdir — create directory (mkdir myfolder).
  • touch — create empty file or update timestamp (touch file.txt).
  • cp — copy files (cp file1.txt file2.txt).
  • mv — move/rename files (mv old.txt new.txt). If filename has spaces: mv "my file.txt" newfile.txt.
  • rm — delete files (rm file.txt). Safe alias: alias rm='rm -i' → asks for confirmation.

file Command

  • Identify file type: file filename.
  • Example outputs: ASCII text, ELF binary, Directory.

less Command

  • Read large text files page by page: less filename.txt.
  • Keys: Space → next page, q → quit.

Advanced Concepts

  • Inodes: store file metadata, point to disk location. View: ls -i.
  • Hard Links: files with the same inode number. Hard link count shown in ls -l.

Linux System Security

  • Root user owns system files; regular users cannot modify them.
  • Restricted folders: /root, /var/log.
  • Rule: only the file owner can change permissions.

Lecture 4: Simple Commands in Linux — Part 2

Root Directory (/)

  • Definition: starting point of the Linux file system.
  • Path separator / separates directories (e.g., /home/user/Documents).
  • Multiple slashes are treated as one (e.g., ///home///user = /home/user).
  • Parent of root: / is its own parent — cd .. in / keeps you in /.

Memory-Based File Systems

/proc Directory

  • Contains process info, CPU details, memory, kernel version.
  • Files may show size 0 but still contain readable info.

/sys Directory

  • Organized system info.
  • Contains hardware, device, USB details.

File & Directory Listing (ls)

OptionPurpose
-lLong listing format
-dDirectory info only
-iShow inode number
-RRecursive listing
  • ls -l → long listing.
  • ls -d → directory info.
  • ls -i → inodes.
  • ls -R → recursive.

Combining Options

Options can be in any order — e.g., ls -ldi = ls -idl.

Short & Long Options

  • Short: ls -i
  • Long: ls --inode
  • Long options are easier to read.

Viewing File Contents

  • less — page by page (less file.txt, quit with q).
  • more — older version of less.
  • cat — show entire file (cat file.txt); not suitable for very large files.

head Command

  • Show first 10 lines: head file.txt.
  • Specify lines: head -n 5 file.txt.

tail Command

  • Show last 10 lines: tail file.txt.
  • Specify lines: tail -n 5 file.txt.

wc (Word Count)

  • Show lines, words, bytes: wc file.txt.
  • Count lines only: wc -l file.txt.

Command & System Discovery

  • which — locate command (which ls).
  • whatis — short description (whatis ls).
  • man — manual page (man ls).
  • apropos — search by keyword (apropos copy = man -k copy).
  • info — detailed documentation (info ls).
  • type — show if alias, built-in, or executable (type cd).

Arguments vs Options

  • Options: modify behavior (e.g., -r).
  • Arguments: files/folders acted upon.

Example: cp -r folder1 folder2

Copying & Moving Files

  • cp — copy files (cp file1.txt file2.txt); recursive: cp -r folder1 folder2.
  • mv — move/rename files (mv old.txt new.txt).

Deleting Files

  • rm — delete files (rm file.txt).
  • Recursive: rm -r foldername.
  • Interactive: rm -i file.txt.

Aliases

  • Create: alias ll='ls -l'
  • Remove: unalias ll
  • List all: alias

Links in Linux

  • Hard Links: same inode, same data. Create: ln file1 file2.
  • Symbolic Links: shortcut, own inode. Create: ln -s original shortcut.

Disk Usage & File Size

  • stat — detailed file info (stat file.txt).
  • du -h — disk usage (human-readable).
  • df -h — free disk space (partitions).

Block Size Concept

  • Files stored in blocks (usually 4 KB).
  • Example: a file >4 KB uses 8 KB (2 blocks).
