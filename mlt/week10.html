Week 10: Short Notes

Lecture 1: Perceptrons and Margin

Core Concepts

Linear Separability with Margin (γ)

  • A dataset is linearly separable with margin γ if there exists a weight vector W* such that:
    • All points are correctly classified.
    • Each point lies at least γ distance away from the decision boundary.
  • Larger γ ⇒ better separation.

Perceptron Convergence

  • If data is linearly separable:
    • The Perceptron algorithm will always converge.
    • It finds a separating hyperplane in finite steps.

Quality of Solution

  • Perceptron finds any valid separator, not the best one.
  • It does not maximize margin.
  • Stops as soon as no misclassification occurs.

Robustness & Generalization

  • Larger margin = better model:
    • More tolerance to noise.
    • Better performance on unseen data.
  • Small margin ⇒ sensitive to small changes.

Key Formulae

Margin Condition:

yᵢ(W*ᵀxᵢ) ≥ γ

Ensures correct classification with margin γ.

Radius of Data (R):

‖xᵢ‖² ≤ R²

All points lie inside a sphere of radius R.

Perceptron Mistake Bound:

Mistakes ≤ R²/γ²

  • Fewer mistakes when:
    • Margin (γ) is large.
    • Data spread (R) is small.

Boundary Hyperplanes:

W*ᵀx = γ and W*ᵀx = −γ

Define the margin boundaries. Decision boundary lies in between.

Examples (Intuition)

Example 1: Multiple Separators
Same dataset → many possible separating lines.
Separator TypeDescription
Wide Margin (Good)Large gap between classes
Thin Margin (Weak)Small gap, less reliable
Perceptron may stop at a thin margin, even if a better one exists.
Example 2: Effect of Noise
Suppose a point shifts slightly (real-world noise):
CaseResult
Small MarginPoint may cross boundary → wrong classification
Large MarginStill correctly classified
Larger margin = more robust model.

Final Takeaway

  • Perceptron:
    • Simple & guaranteed to converge.
    • Does not find optimal (max-margin) separator.
  • Goal ahead:
    • Find a method that maximizes margin.
    • Improves robustness.

This leads to Support Vector Machines (SVM).

One-Line Summary: Perceptron finds a separator, but the best models are those that maximize the margin.

Lecture 2: Maximum Margin: Formulation

Core Concepts

Objective of Maximum Margin

  • Goal: Find weight vector w such that:
    • Data is correctly classified.
    • Margin γ is maximized.
  • Larger margin ⇒ better generalization.

Problem of Arbitrary Scaling

  • Constraint: yᵢ(wᵀxᵢ) ≥ γ
  • Issue:
    • If we multiply w by any constant, γ also scales.
    • Decision boundary does not change.
  • Margin can become artificially large ⇒ ill-defined problem.

Fixing the Problem (Grounding)

We remove scaling ambiguity in two ways:

  1. Grounding w
    • Fix length: ‖w‖ = 1
    • Then maximize γ.
  2. Grounding γ (Standard Approach)
    • Fix margin: γ = 1
    • Then optimize w.
    • This is the standard SVM formulation.

Width of Margin

  • Defined as distance between: wᵀx = 1 and wᵀx = −1
  • Key idea: Width ∝ 1/‖w‖
  • Smaller ‖w‖ ⇒ larger margin.

Primal Optimization Problem

  • Final goal: Find w that maximizes margin.
  • Equivalent to minimizing length of w.

Key Formulae

Margin Constraint: yᵢ(wᵀxᵢ) ≥ γ

Grounded Formulation (γ=1): yᵢ(wᵀxᵢ) ≥ 1

Width (Relation with w): Width ∝ 1/‖w‖

Final Primal Optimization:

min over w of (1/2)‖w‖²   subject to   yᵢ(wᵀxᵢ) ≥ 1

This is the core SVM optimization problem.

Examples & Intuition

Example 1: Scaling Problem
  • Suppose w gives margin = 5.
  • Scale w→2w: New margin = 10.
  • Decision boundary unchanged.
  • Margin increase is fake (just scaling).
Example 2: Grounding γ=1
  • If wᵀx = 5.
  • Scale: w′ = w/5.
  • Now w′ᵀx = 1.
  • Makes all solutions comparable.
Example 3: Width vs Length of w
CaseInterpretation
Small ‖w‖Large margin (good)
Large ‖w‖Small margin (bad)
Minimizing ‖w‖ = maximizing margin.
Example 4: Non-Separable Data
  • If no w satisfies: yᵢ(wᵀxᵢ) ≥ 1
  • Dataset is not linearly separable.

Final Takeaway

  • Scaling issue makes raw margin maximization meaningless.
  • Fix by setting γ = 1.
  • Final objective: Minimize ‖w‖² while ensuring correct classification.

Next Step

  • Study Dual Problem:
    • Helps in non-linear classification.
    • Enables kernel methods.
  • Leads to full Support Vector Machines (SVM).
One-Line Summary: Maximizing margin = minimizing weight magnitude under correct classification constraints.

Lecture 3: Constrained Optimization

Core Motivation

Goal (in Classification)

  • Find weight vector w such that:
    • Correctly classifies all data.
    • Has minimum length (⇒ maximum margin).
  • Equivalent to minimizing ‖w‖ with constraints.

The Problem: General constrained optimization:

min f(w)   subject to   g(w) ≤ 0

Hard to solve directly → need a better approach.

Why Duality?

  • Simplifies optimization.
  • Provides deeper insights.
  • Enables advanced methods (like kernels in SVM).

Lagrangian Function

To handle constraints, we combine them into one function:

L(w,α) = f(w) + αg(w)

  • w: model parameters.
  • α: Lagrange multiplier (α ≥ 0).

Key Idea

We evaluate: max over α≥0 of L(w,α)

Case 1: Constraint Violated (g(w) > 0)

Example: f(w)=−100, g(w)=5 → L(w,α)=−100+5α

As α→∞, L(w,α)→∞.

Interpretation: Invalid solutions get infinite penalty.

Case 2: Constraint Satisfied (g(w) ≤ 0)

Example: f(w)=100, g(w)=−5 → L(w,α)=100−5α

Maximization gives α=0. Result: Value = f(w).

Special Case: g(w)=0

L(w,α) = f(w) for any α

Min-Max Formulation

The constrained problem becomes:

min over w of max over α≥0 of [f(w) + αg(w)]

  • If constraint violated → value = ∞.
  • If satisfied → value = f(w).
  • Minimum occurs only in feasible region.

Convex Duality

  • General rule: Cannot swap min and max.
  • Exception (Convex Case): If f(w) and g(w) are convex:

max over α≥0 of min over w of [f(w) + αg(w)]

  • This is the Dual Problem.
  • Same solution as primal (strong duality).

Multiple Constraints

For k constraints: g₁(w), g₂(w), …, g_k(w)

Lagrangian with Multiple Constraints:

L(w,α₁,...,α_k) = f(w) + Σ αᵢgᵢ(w), for i = 1 to k

  • Each constraint has its own αᵢ ≥ 0.
  • If any constraint violated → Lagrangian → ∞.
  • If all satisfied → Value reduces to f(w).

Examples & Intuition

Example 1: Penalty Mechanism
  • Violating constraint → huge penalty (∞).
  • Forces solution to stay feasible.
Example 2: Valid Region
Inside feasible region: Optimization behaves like normal minimization of f(w).
Example 3: Convex Case
  • For convex functions: Primal = Dual.
  • Makes problem easier to solve.

Final Takeaway

  • Lagrangian converts constrained problem → unconstrained form.
  • Duality allows swapping min and max (if convex).
  • Important for:
    • Support Vector Machines (SVM).
    • Kernel tricks.
One-Line Summary: Lagrangian turns constraints into penalties, and duality lets us solve optimization more efficiently (especially in convex problems).

Lecture 4: Formulating the Dual Problem

The Primal Problem

Objective

  • Find weight vector W that:
    • Minimizes length (⇒ maximizes margin).
    • Correctly classifies all points.

Primal Optimization:

min over W of (1/2)‖W‖²   subject to   yᵢ(Wᵀxᵢ) ≥ 1

Standard Constraint Form

Convert to gᵢ(W) ≤ 0:

gᵢ(W) = 1 − yᵢ(Wᵀxᵢ) ≤ 0

Convexity

  • Objective: Quadratic (convex).
  • Constraints: Linear (convex).

Ensures strong duality (min-max swap valid).

Lagrangian Formulation

Lagrangian Function:

L(W,α) = (1/2)‖W‖² + Σ αᵢ(1 − yᵢWᵀxᵢ), for i = 1 to n

with αᵢ ≥ 0.

Min-Max Conversion

  • Original: min over W of max over α≥0 of L(W,α)
  • Dual form: max over α≥0 of min over W of L(W,α)

Solving Inner Minimization (Find Optimal W)

Gradient w.r.t W:

∇_W L = W − Σ αᵢyᵢxᵢ = 0, for i = 1 to n

Optimal Weight Vector:

W* = Σ αᵢyᵢxᵢ, for i = 1 to n

Interpretation: W* is a linear combination of training points, weighted by labels yᵢ and importance αᵢ.

Dual Problem

Substitution: Insert W* into Lagrangian.

Dual Optimization Problem:

max over α≥0 of ( Σ αᵢ − (1/2) Σ αᵢαⱼyᵢyⱼxᵢᵀxⱼ )

Key Observation: Depends only on dot products xᵢᵀxⱼ.

Advantages of Dual Problem

  • Lower Dimensionality
    • Primal: works in D (features).
    • Dual: works in n (data points).
    • If D ≫ n, dual is faster.
  • Simpler Constraints
    • Only αᵢ ≥ 0.
    • Easier optimization.

Kernel Trick:

Replace: xᵢᵀxⱼ → K(xᵢ,xⱼ)

Enables non-linear classification and high-dimensional mapping.

Support Vectors (Key Concept)

Final Weight Vector:

W* = Σ αᵢ*yᵢxᵢ, for i = 1 to n

Role of αᵢ*:

CaseMeaning
αᵢ* = 0Point not important
αᵢ* > 0Important point

Support Vectors: Points with αᵢ* > 0. They define the decision boundary and lie on the margin.

Examples & Intuition

  • Contribution of Points: Only a few points have αᵢ > 0. Model depends only on support vectors.
  • Geometry Insight: Support vectors are closest to boundary and define margin. Removing them changes classifier.

Kernel Trick: Instead of explicit features, use similarity function K(xᵢ,xⱼ). Enables complex boundaries.

Final Takeaway

  • Primal → optimize W.
  • Dual → optimize α.
  • Key idea: Solution depends only on support vectors.
One-Line Summary: SVM dual form expresses the model as a weighted combination of key data points (support vectors), enabling efficient optimization and kernel methods.

Lecture 5: Support Vector Machine

Lagrangian Duality

Duality Principle: For convex problems: Primal = Dual (same optimal value).

Primal Problem:

min over w of max over α≥0 of [f(w) + αg(w)]

Dual Problem:

max over α≥0 of min over w of [f(w) + αg(w)]

Optimality Condition: At optimum: f(w*) = Dual objective at α*

Both formulations give the same result.

Complementary Slackness

Condition: αᵢ* ⋅ gᵢ(w*) = 0

Meaning:

CaseInterpretation
αᵢ* > 0gᵢ(w*) = 0 (point lies on boundary)
gᵢ(w*) < 0αᵢ* = 0 (point inside margin)

In SVM

Constraint: gᵢ(w) = 1 − yᵢ(Wᵀxᵢ)

Slackness becomes: αᵢ*[1−yᵢ(Wᵀxᵢ)] = 0

Support Vectors

Definition: Points where αᵢ* > 0. These are called Support Vectors.

Geometric Meaning

They satisfy: yᵢ(Wᵀxᵢ) = 1. Lie exactly on margin boundaries.

Sparsity: Only support vectors contribute to the model:

w* = Σ αᵢ*yᵢxᵢ, for i = 1 to n

Non-support points (αᵢ* = 0) do not contribute.

Example (Data Compression)
Dataset: 1 billion points → Support vectors: few hundred.
Store only support vectors ⇒ huge memory saving.

Kernel SVM & Prediction

Idea: Replace dot product with kernel: xᵢᵀxⱼ → K(xᵢ,xⱼ)

Prediction Function:

Prediction = Σ αᵢ*yᵢK(xᵢ, x_test), for i ∈ SV

Key Insight: Only sum over support vectors. Efficient even in high dimensions.

Handling Noise & Outliers

Problem: Standard SVM assumes perfect linear separability.

Fails if:

  • Outliers exist.
  • Data overlaps.

Solutions

  1. Kernels
    • Used when boundary is non-linear.
    • Example: circular or polynomial separation.
  2. Soft Margin SVM
    • Used when data has noise.
    • Allows small violations of margin.
Example: One wrong point inside cluster:
  • Hard SVM → fails.
  • Soft SVM → tolerates it.

Final Takeaway

  • Duality makes SVM solvable efficiently.
  • Complementary slackness identifies important points.
  • Only support vectors matter.
  • Kernel trick enables non-linear classification.
  • Soft margin handles real-world noisy data.
One-Line Summary: SVM works by focusing only on critical boundary points (support vectors), using duality and kernels to efficiently handle complex and high-dimensional data.

Lecture 6: Soft Margin SVM

Core Concepts

Limitation of Hard Margin SVM

Constraint: yᵢ(wᵀxᵢ) ≥ 1

  • Works only if data is perfectly separable.
  • Fails when noise or outliers are present.
  • No feasible w ⇒ model fails.

Slack Variables (ξᵢ)

  • Introduced to relax constraints.
  • Act like a penalty (or "bribe").

Meaning of ξᵢ:

CaseInterpretation
ξᵢ = 0Correct & outside margin
0 < ξᵢ < 1Inside margin but correct side
ξᵢ ≥ 1Misclassified point

Soft Margin SVM

  • Goal: Maximize margin and minimize classification errors.
  • Balances margin vs mistakes.

Hyperparameter C

Controls trade-off:

C ValueBehavior
Small CAllows more errors, wider margin
Large CFewer errors, narrower margin

Chosen using cross-validation.

Key Formulae

Soft Margin Objective:

min over w,ξ of [(1/2)‖w‖² + C Σ ξᵢ], for i = 1 to n

Constraints:

Modified margin constraint: yᵢ(wᵀxᵢ) ≥ 1 − ξᵢ

Non-negativity: ξᵢ ≥ 0

Examples & Intuition

Example 1: Why Slack is Needed
  • If one outlier exists:
    • Hard SVM → fails.
    • Soft SVM → allows small violation.
  • ⇒ Model becomes robust.
Example 2: Case w=0
If slack not penalized:
  • Choose w=0 (minimum length).
  • All points pay ξᵢ=1.
  • ⇒ Bad solution → need penalty term.
Example 3: Effect of C=0
  • No penalty on slack.
  • Model ignores errors.
  • Result: w=0.
  • ⇒ Useless classifier.
Example 4: Effect of C=∞
  • Slack too costly.
  • Forces ξᵢ=0.
  • ⇒ Becomes Hard Margin SVM.
Example 5: Trade-off Intuition
ScenarioOutcome
Large margin + few errorsIdeal
Large margin + many errorsOver-relaxed
Small margin + no errorsOverfitting

Important Insight

Objective combines:

  • ‖w‖² → controls margin.
  • Σξᵢ → controls errors.

Different units balanced by C.

Final Takeaway

  • Hard SVM = strict, unrealistic.
  • Soft SVM = flexible, practical.
  • Handles:
    • Noise.
    • Outliers.
    • Non-perfect data.

    • Kernelization.
    • Efficient optimization.
One-Line Summary: Soft Margin SVM allows controlled mistakes using slack variables, balancing margin size and classification errors through the parameter C.
