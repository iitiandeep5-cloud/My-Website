Week 11: Short Notes

Lecture 1: Dual Formulation for Soft Margin SVM

Core Idea: Soft Margin SVM allows classification errors to handle:

  • Noisy data
  • Non-linearly separable datasets

Instead of forcing perfect separation, it balances margin size and classification errors.

Key Concepts

Slack Variables (ξᵢ)

  • Measure violation of margin constraint
  • Interpretation:
    • ξᵢ = 0 → correctly classified
    • 0 < ξᵢ ≤ 1 → inside margin
    • ξᵢ > 1 → misclassified

Hyperparameter (C)

Controls trade-off between margin width and classification errors:

C ValueBehavior
Small CAllows more errors → wider margin
Large CPenalizes errors heavily → narrower margin

Think of C as the strictness level of the model.

Kernelization

Replace dot product with kernel function to handle non-linear data. Examples:

  • Linear kernel
  • Polynomial kernel
  • RBF kernel

Box Constraint

In dual form: 0 ≤ αᵢ ≤ C. Limits influence of each data point.

Mathematical Formulation

(A) Primal Problem

min over w,ξ of (1/2)‖w‖² + C Σ ξᵢ, for i = 1 to n

(B) Lagrangian

L = (1/2)‖w‖² + C Σξᵢ + Σαᵢ(1−yᵢwᵀxᵢ−ξᵢ) + Σβᵢ(−ξᵢ)

(C) Optimality Conditions

  • Weight vector: w* = Σαᵢyᵢxᵢ
  • Constraint: αᵢ + βᵢ = C

(D) Dual Problem

max over α of ( Σ αᵢ − (1/2)αᵀYᵀXᵀXYα ), for i = 1 to n

Subject to:

0 ≤ αᵢ ≤ C

Important Examples

Case 1: C=0
  • No penalty for errors
  • Result: αᵢ = 0, w = 0
  • Model does nothing (completely relaxed)
Case 2: C→∞
  • Errors not allowed
  • Equivalent to Hard Margin SVM
  • Works only if data is perfectly separable

Key Insights

  • Handles outliers by allowing controlled violations
  • Sparse solution: only support vectors matter
  • Easy optimization due to box constraint:
    • If αᵢ < 0 → 0
    • If αᵢ > C → C
Intuition Summary: Soft Margin SVM tries to: "Maximize margin while minimizing classification mistakes."

One-Line Memory Trick:
  • Hard Margin = No mistakes allowed
  • Soft Margin = Some mistakes allowed (controlled by C)

Lecture 2: Complementary Slackness Conditions for Soft-Margin SVM

Core Idea: At optimality, the extra terms in the Lagrangian vanish (become zero). This gives Complementary Slackness (CS) conditions, which help us understand:

  • Which points matter
  • Where they lie geometrically

Key Conditions

CS Condition 1 (CS1): αᵢ*(1 − yᵢw*ᵀxᵢ − ξᵢ*) = 0

Meaning: Either αᵢ = 0, OR Constraint is exactly tight

CS Condition 2 (CS2): βᵢ*ξᵢ* = 0

Meaning: Either βᵢ = 0, OR Slack ξᵢ = 0

Feasibility Relation: αᵢ* + βᵢ* = C

Connects α and β using hyperparameter C.

Case Analysis

We classify points based on αᵢ*:

Case 1: αᵢ* = 0 → Non-Support Vectors

  • Derivation: βᵢ* = C. Since βᵢ* ≠ 0, from CS2: ξᵢ* = 0.
  • Geometry: yᵢw*ᵀxᵢ ≥ 1. Point is correctly classified, outside or on margin.
  • Conclusion:
    • Not a support vector
    • Does not affect decision boundary

Case 2: 0 < αᵢ* < C → Margin Support Vectors

  • Derivation: βᵢ* ≠ 0 ⟹ ξᵢ* = 0. αᵢ* ≠ 0 ⟹ 1 − yᵢw*ᵀxᵢ − ξᵢ* = 0.
  • Geometry: yᵢw*ᵀxᵢ = 1. Point lies exactly on margin.
  • Conclusion:
    • Support vector
    • Defines hyperplane

Case 3: αᵢ* = C → "Danger Zone" Support Vectors

  • Derivation: βᵢ* = 0. From CS1: ξᵢ* = 1 − yᵢw*ᵀxᵢ
  • Geometry: yᵢw*ᵀxᵢ ≤ 1. Point lies inside margin or misclassified.
  • Two Types of Points:
    1. Inside Margin (but correct): 0 ≤ yᵢw*ᵀxᵢ < 1
    2. Misclassified (Outliers): yᵢw*ᵀxᵢ < 0
  • Conclusion:
    • Strong support vectors
    • Maximum influence (αᵢ = C)

Final Summary

Support Vectors in Soft Margin SVM

A point is a support vector if: αᵢ* > 0

TypeConditionMeaning
Margin SV0 < αᵢ < COn hyperplane
Error SVαᵢ = CInside margin / misclassified

Non-Support Vectors

ConditionMeaning
αᵢ = 0No role in model

Intuition: Think of αᵢ as importance weight:

  • αᵢ = 0 → ignore point
  • Small αᵢ → normal support vector
  • αᵢ = C → critical/difficult point
One-Line Memory Trick: "Only points with α > 0 matter — rest are invisible."

Lecture 3: Summary for Soft-Margin SVM

Core Concepts

Primal vs Dual View

  • Primal: Focus on finding optimal w* (hyperplane).
  • Dual: Focus on αᵢ* (importance of each data point).

Key Idea: Final solution depends on α values, not all data points.

Support Vectors & Sparsity

  • Only points with αᵢ* > 0 matter.
  • These are called Support Vectors.

Result: Model is sparse → depends on few points only.

Complementary Slackness (CS)

Links:

  • αᵢ (importance)
  • ξᵢ (error)
  • Margin position

Helps identify:

  • Which points are support vectors
  • Where they lie geometrically

Soft Margin Properties

  • Handles outliers
  • Works with non-linear data (via kernels)
  • Easy optimization due to box constraint: 0 ≤ αᵢ ≤ C

Important Formulae

Feasibility Condition: yᵢw*ᵀxᵢ + ξᵢ* ≥ 1

Slack Variable Meaning: ξᵢ* ≥ 1 − yᵢw*ᵀxᵢ

Shows how much a point violates the margin.

Classification of Points

Case 1: Outside Margin

  • Condition: yᵢw*ᵀxᵢ > 1
  • Result: αᵢ* = 0
  • Interpretation:
    • Correctly classified
    • Far from boundary
    • No contribution

Case 2: On Margin

  • Condition: yᵢw*ᵀxᵢ = 1
  • Result: 0 < αᵢ* < C
  • Interpretation:
    • Lies exactly on hyperplane
    • Support vector

Case 3: Inside Margin / Misclassified

  • Condition: yᵢw*ᵀxᵢ < 1
  • Result: αᵢ* = C
  • Interpretation:
    • Inside margin OR wrong side
    • Most important points

Summary Table

αᵢ* (Dual View)Margin (Primal View)Meaning
αᵢ = 0≥ 1Ignore point
0 < αᵢ < C= 1On margin
αᵢ = C≤ 1Inside margin / misclassified

Visualization (2D Intuition)

Hyperplanes:

  • wᵀx = 1 → positive margin
  • wᵀx = −1 → negative margin

Points:

  • Far outside → α = 0
  • On lines → support vectors
  • Between/incorrect → α = C

Practical Insights

  • Optimization: Fast solvers exist (near linear time). Easy due to clipping (box constraint).
  • SVM vs Logistic Regression: Both perform well in practice. Strategy: train both → choose best via validation.
  • Use Cases: Best for structured/tabular data and high-dimensional features.

Bigger Picture (ML Context)

Soft Margin SVM is part of the classification family:

  • Naïve Bayes
  • Decision Trees
  • k-NN
  • Logistic Regression
  • Perceptron

Advanced methods:

  • Bagging
  • Boosting
Final Intuition: "Only difficult or boundary points shape the decision boundary."
  • Easy points → ignored
  • Hard points → define model
One-Line Memory Trick:
  • α = 0 → useless
  • 0 < α < C → boundary
  • α = C → problematic points

Lecture 4: Overfitting and Underfitting

Types of Supervised Learning Models

Generative Models

  • Learn joint probability: P(X,Y)
  • Model how data is generated.
  • Examples: Naïve Bayes, Gaussian Discriminant Analysis (GDA).
  • Idea: "Model the data distribution first, then classify."

Discriminative Models

Learn decision boundary or conditional probability: P(Y|X)

  • Examples: K-Nearest Neighbors (KNN), Decision Trees, Support Vector Machines (SVM).
  • Idea: "Directly separate classes."

Unified Framework

Most models follow: Loss + Regularization

  • Loss: Fit to data.
  • Regularization: Control complexity.

Ensemble Learning (Meta Models)

Core Idea: Combine many weak learners → strong learner.

Weak Learner

  • Slightly better than random.
  • Example: Binary classification ≈ 55–60% accuracy.

Strong Learner: High accuracy after combining weak models.

Why it works? Different models capture different patterns → combining improves prediction.

Overfitting vs Underfitting

FeatureOverfittingUnderfitting
DefinitionLearns noiseMisses pattern
ModelToo complexToo simple
Training ErrorVery low (≈0)High

Intuition:

  • Overfitting → "memorizes data."
  • Underfitting → "doesn't learn enough."

Bias−Variance Trade-off

Total Error Concept: Error ≈ Bias + Variance

Bias

  • Error due to wrong assumptions.
  • Example: Fitting a line to a curve.
  • High Bias → underfitting.

Variance

  • Sensitivity to data changes.
  • Example: Model changes drastically with small data changes.
  • High Variance → overfitting.

Trade-off Table

Model ComplexityBiasVariance
LowHighLow
HighLowHigh

Goal: Balance both to minimize test error.

Key Conceptual Relationship: Structure + Noise = Data (Labels)

Model should:

  • Learn structure
  • Ignore noise

Important Examples

Decision Trees
  • Overfitting: Deep tree → memorizes noise.
  • Underfitting: Shallow tree (depth = 1) → too simple.
Regression (Sine Curve Example)
  • True pattern → sinusoidal curve.
  • Underfitting: Linear model → misses curve.
  • Overfitting: High-degree polynomial → fits noise.
K-Nearest Neighbors (KNN)
  • Small K: Complex boundary → overfitting.
  • Large K: Smooth boundary → underfitting.
  • Extreme case: K=N → predicts same value everywhere.

Controlling Bias−Variance

Use hyperparameters:

Role of Cross-Validation: Helps choose best parameter, balances bias & variance.

Final Intuition: "Simple models miss patterns, complex models chase noise — best model finds the balance."

One-Line Memory Trick:
  • Underfit = High Bias
  • Overfit = High Variance
  • Goal = Balance both

Lecture 5: Bagging

Core Idea of Bagging

  • Bagging (Bootstrap Aggregation): Combines multiple models to reduce variance.
  • Best for high-variance models (e.g., deep decision trees).

Key Idea: "Train many models on different data → average their predictions."

Why Bagging Works

  • Power of Averaging: Averaging multiple models reduces fluctuations and stabilizes predictions.
  • Works best when models are independent or less correlated.

Bootstrapping

  • Definition: Create multiple datasets from original dataset using sampling with replacement.
  • Key Properties:
    • Each dataset (bag) has same size n.
    • Some points appear multiple times, some may not appear at all.
Example
Original dataset: D = {x₁, x₂, x₃, x₄, x₅}
Bootstrap sample: D₁ = {x₃, x₄, x₅, x₃, x₅}

Aggregation

  • After training: models h₁, h₂, …, h_M.
  • Final prediction:

H*(x) = sign( (1/M) Σ hᵢ(x) ), for i = 1 to M

  • Classification: Majority vote.
  • Regression: Average output.

Weak Learners in Bagging

  • Usually deep decision trees.
  • High variance, low bias.
  • Bagging reduces their variance.

Important Formulae

Sample Mean (MLE):

μ_ML = (1/n) Σ xᵢ, for i = 1 to n

Averaging reduces variance.

Probability a Point is Not Selected: (1−1/n)ⁿ

Probability a Point is Selected: 1−1/e ≈ 0.67

Approximately 67% of data appears in each bag.

Random Forest

  • Definition: Bagging applied to decision trees with extra randomness via feature selection.
  • Feature Bagging: At each split, randomly select subset of features and choose best split only from them.
  • Why it helps: Trees become less correlated → averaging gives stronger variance reduction.
Example: Total features = 1000. At a node → pick only 4 features randomly. Split based only on those 4.

Feature Selection Rule

TaskFeatures Used
Classification√d
Regressiond/3 or d/5

Intuition Example

  • Gaussian Mean Estimation:
    • Single sample → high variance.
    • Average of samples → stable estimate.

Same idea behind bagging.

Advantages

  • Parallel Training: Each model independent, can run on multiple CPUs.
  • Robustness: Noise learned by individual trees gets averaged out.
  • Better Generalization: Reduces overfitting significantly.
Final Intuition: "Many noisy models → averaged → smooth & reliable model."

One-Line Memory Trick: Bagging = Bootstrap + Average = Reduce Variance

Lecture 6: Boosting

Core Idea of Boosting

  • Boosting: Converts weak learners into strong learners using an iterative process.
  • Key Idea: "Focus more on mistakes in each step and improve them."

Weak Learner

  • Slightly better than random (≈ 55–60%).
  • Usually simple models, high bias, low variance.

Strong Learner

  • Combination of weak learners.
  • Can achieve very high accuracy (even zero training error).

AdaBoost (Adaptive Boosting)

  • Adjusts importance (weights) of data points.
  • Misclassified points → more focus in next round.

Decision Stumps (Common Weak Learners)

  • Definition: Very small decision tree (1−2 levels).
  • Makes decision based on one feature.
  • Example: "Is feature1 < threshold?"
  • Properties: Fast, simple, low accuracy individually, perfect for boosting.

AdaBoost Algorithm Steps

Step 1: Initialization: Assign equal weights: D₁(i) = 1/n

Step 2: Iterative Training (t = 1…T)

  1. Train Weak Learner: Train model hₜ using weighted data.
  2. Compute Error: Error = sum of weights of misclassified points.
  3. Compute Classifier Importance:

    αₜ = (1/2) ln( (1−εₜ)/εₜ )

    Lower error → higher importance.
  4. Update Weights:
    • Wrong prediction: Dt+1(i) = Dₜ(i)·e^(αₜ)
    • Correct prediction: Dt+1(i) = Dₜ(i)·e^(−αₜ)
  5. Normalize: Ensure Σ Dt+1(i) = 1.

Step 3: Final Model

H*(x) = sign( Σ αₜhₜ(x) ), for t = 1 to T

Weighted majority vote.

Key Intuition

  • Misclassified points → get higher weight.
  • Correct points → get lower weight.
  • Model keeps learning from mistakes.

Theoretical Insights

  • Training Error: If weak learner is slightly better than random, training error → 0 as T increases.
  • Gamma (γ): Measures improvement over random.
    • Example: Accuracy = 60%, Random = 50%, γ=0.1.
  • Overfitting Behavior: Often does not overfit quickly; test error may continue to improve.
  • Reason: Increases margin over time.

Practical Properties

  • Serial Nature: Each step depends on previous step → cannot parallelize (unlike Bagging).
  • Low Tuning Needed: Works well with default settings.
  • Best Use Case: Works best with simple models (decision stumps). Not ideal with already complex models.

Examples

Weighted Sampling Example: Weight = 0.7 → 70% chance of being selected.
Weight Adjustment Example: Dataset = 1000 points.
  • Correct: 600
  • Wrong: 400
  • Those 400 points get higher weight next round → model focuses on them.
