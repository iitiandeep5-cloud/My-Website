Week 12: Short Notes

Lecture 1: Classification Loss Functions

Problem Setup

We are given training data: (x₁, y₁), (x₂, y₂), …, (xₙ, yₙ)

where: xᵢ ∈ Rᵈ (feature vector), yᵢ ∈ {+1,−1} (label)

Goal: Learn a function H:Rᵈ → {+1,−1}

Linear Classifier

We assume a linear decision boundary: H(x) = sign(Wᵀx + b)

W: weight vector   b: bias

Interpretation:

  • If Wᵀx + b > 0 ⇒ class = +1
  • If Wᵀx + b < 0 ⇒ class = −1

Dimensionality Trick (Bias Removal)

  • Add an extra feature: x₀ = 1
  • Extend vector → x ∈ Rᵈ⁺¹
  • Then bias b becomes part of W

Model becomes: H(x) = sign(Wᵀx)

Performance Measure: 0–1 Loss

Indicator Function: I(z) = 1 if z is true, 0 otherwise

Total Training Error: Σ I(H(xᵢ) ≠ yᵢ), for i = 1 to n

Single Point Loss: I(y·G(x) < 0)

Meaning:

  • y·G(x) > 0 ⇒ correct prediction → loss = 0
  • y·G(x) < 0 ⇒ wrong prediction → loss = 1

Example Table

yG(x)y·G(x)Result
+12+2Correct
-13-3Wrong

Why is Optimization Hard?

Minimizing 0–1 loss is NP-hard.

Reasons:

  • Discontinuous → sudden jump from 0 → 1
  • Non-convex → many local minima
  • No efficient algorithm guaranteed

Conclusion: Direct optimization is impractical.

Solution: Surrogate Loss Functions

Idea: Replace 0–1 loss with a smooth, convex loss.

Advantages:

  • Easier to optimize
  • Used in real algorithms

Examples:

  • Logistic Regression → log loss
  • SVM → hinge loss
  • Perceptron → perceptron loss

Squared Loss (Regression Approach)

Treat classification as regression: (G(x)−y)²

Equivalent form (for y ∈ {+1,−1}): (y·G(x)−1)²

Example:
  • y = +1
  • If G(x) = 1 ⇒ loss = 0 (perfect)
  • If G(x) = 5 ⇒ loss is large
Even correct predictions can get high penalty.

Problems with Squared Loss

  1. Penalizes "Too Correct" Predictions
    • Loss increases if y·G(x) is very large
    • But 0–1 loss = 0 (already correct)
  2. Sensitive to Outliers
    • Far-away points dominate training
    • Can distort decision boundary
Final Intuition:
  • 0–1 loss = ideal but not computable efficiently
  • Surrogate losses are practical substitutes
  • Different ML algorithms = different surrogate losses
One-Line Summary: Binary classification = find a hyperplane that separates data, but since exact error minimization is hard, we optimize smooth approximations instead.

Lecture 2: SVM and Logistic Loss

Core Idea

  • 0–1 loss is hard to optimize
  • Surrogate losses (smooth + convex) make learning efficient and stable

Hinge Loss (Used in SVM)

Formula: max(0, 1 − y·G(x))

Full SVM Objective:

(1/2)‖w‖² + Σ max(0, 1 − yᵢG(xᵢ)), for i = 1 to n

Intuition: y·G(x) = margin → measures confidence of prediction.

Key Points:

  • No penalty if correct and confident (margin ≥ 1)
  • Penalizes wrong predictions and weakly correct predictions

Logistic Loss (Used in Logistic Regression)

Formula: log(1 + e^(−y·G(x)))

Intuition:

  • Derived from maximum likelihood estimation

Squared Loss (For Comparison)

Formula: (G(x)−y)²

  • Sensitive to outliers
  • Not ideal for classification

Lecture 3: Perceptron and Boosting Loss

Perceptron as Gradient Descent

Core Idea: Perceptron = Stochastic Gradient Descent (SGD). Updates weights using one data point at a time.

Standard Update Rule: Wₜ₊₁ = Wₜ + yₜxₜ

Applied only when prediction is wrong.

Gradient Descent View: General GD update: Wₜ₊₁ = Wₜ − η∇L(W)

  • Learning rate η = 1
  • Uses single sample (SGD)

Perceptron Loss Function: max(0, −y·Wᵀx)

Difference from SVM:

  • SVM: max(0, 1−yWᵀx)
  • Perceptron: removes margin "1 −"

Example

yWᵀxy·WᵀxLossUpdate
+1-2-22Yes
+1330No

Takeaway: Perceptron updates only on mistakes.

Hinge Loss & Subgradients

Standard Hinge Loss: max(0, 1−y·Wᵀx)

Gradient Cases

ConditionGradient
yWᵀx < 0−yx
yWᵀx > 00

Non-Differentiability: At yWᵀx = 0, function is not smooth.

Subgradient Concept:

  • A subgradient is a valid "generalized gradient"
  • At non-smooth points → multiple possible slopes

At yWᵀx = 0: Subgradient lies between [−yx, 0].

Perceptron Choice:

  • Always picks −yx
  • Treats boundary case as mistake

Boosting & Exponential Loss

Exponential Loss: e^(−y·h(x))

Idea:

  • Boosting builds model step-by-step
  • Adds a new weak learner each round

Mechanism:

  • Acts like coordinate descent
  • Focuses more on misclassified points

Example

yh(x)y·h(x)Loss

-12-2large

Takeaway: Boosting strongly penalizes wrong predictions → improves accuracy.

Convex Surrogates vs Neural Networks

Convex Surrogate Methods:

  • Examples: SVM → Hinge Loss, Logistic Regression → Logistic Loss
  • Convex function = single global minimum
  • Easy to optimize, reliable solutions

Neural Networks:

  • Loss function is non-convex
  • Consequences: multiple local minima, no guarantee of global optimum
  • Still effective: good local minima → good performance
  • Very powerful for complex data

Historical Link: Neural networks are inspired by Perceptron.

Lecture 4: Neural Networks

Core Idea: Supervised Learning Framework

Goal: Learn a model by minimizing: Loss Function + Regularization

Components:

  • Loss Function: Measures prediction error (depends on data)
  • Regularizer: Controls model complexity (e.g., keeps weights W small)

Convex vs Non-Convex

TypeAlgorithmsProperty
ConvexSVM, Logistic RegressionOne global minimum
Non-ConvexNeural NetworksMany local minima

Important:

  • Convex → easy optimization
  • Neural Networks → more powerful but harder to train

Neural Network Basics

Definition: Inspired by biological neurons. Extension of Perceptron. Learns non-linear relationships.

Mathematical Model (1 Hidden Layer):

Input vector: X = [x₁, x₂, …, xd]ᵀ

Hidden layer computation: Each neuron computes: a(WᵢᵀX)

  • Linear part: WᵢᵀX
  • Activation: a(·)

Final output: ŷ = Σ W_out(i) · a(WᵢᵀX), for i = 1 to k

Parameters of Network:

  • W₁, W₂, …, Wₖ: hidden layer weights
  • W_out: output weights
  • k: number of hidden neurons
  • a(·): activation function

Activation Functions

Purpose: Add non-linearity → makes network powerful.

  • Sigmoid Function: a(z) = 1/(1+e^(−z)). Properties: output between 0 and 1, smooth & differentiable. Use: probability / soft decision.
  • ReLU (Most Popular): a(z) = max(0,z). Properties: simple & fast, avoids vanishing gradient.
  • Step Function: a(z) = 1 if z ≥ 0, 0 if z < 0. Hard decision, not smooth → difficult to optimize.
  • TanH: Output range: (-1, 1), centered around zero.

Intuition & Examples

  • Biological Analogy: Like real neurons: input signal → processed → neuron "fires"
  • Voting Interpretation: Each hidden neuron detects a feature; activation = "vote"; output layer combines votes
  • Example (Image Recognition):
    • Input = image pixels
    • Hidden nodes learn features: edges, curves, textures
    • Final output combines these features

One-Line Summary: Neural networks extend linear models by adding layers and non-linear activations, enabling them to learn complex patterns at the cost of harder (non-convex) optimization.

Lecture 5: Computing Parameters of a Neural Networks

Neural Network Parameters & Representation

Parameter Vector: All weights in the network are combined into one vector:

θ = {W₁, W₂, …, Wₖ, W_out}

This represents the entire model.

High Dimensionality: As number of layers (L) increases, and number of neurons increases, parameters (θ) become very large.

Network Structure:

  • Input Layer → receives data
  • Hidden Layers (1 to L) → feature learning
  • Output Layer → prediction

Number of neurons per layer = design choice.

Loss Functions

(A) Regression Loss – Squared Loss: (NN(xᵢ; θ) − yᵢ)²

Total Loss: Σ (NN(xᵢ; θ) − yᵢ)², for i = 1 to n

Example: True value = 5, Prediction = 3
Loss = (3−5)² = 4

(B) Binary Classification – Cross Entropy:

Output probability: σ(z) = 1/(1+e^(−z))

Idea:

  • Predicts probability P(y = 1 | x)
  • Measures how close prediction is to actual label

Example

PredictionTrue LabelLoss
0.91Low
0.90High

Key Insight: Wrong confident predictions → very high loss.

Training: Gradient Descent & Backpropagation

Gradient Descent: Update parameters to minimize loss: θ ← θ − η∇L(θ)

Backpropagation: Efficiently computes gradients using chain rule.

How it Works:

  1. Forward pass → compute output
  2. Compute loss
  3. Backward pass → compute gradients
  4. Update weights

Intuition:

  • Change in one layer affects next layers
  • Backprop "propagates error backward"

Non-Convex Optimization:

  • Neural networks → non-convex loss
  • Consequences: multiple local minima, no guarantee of global optimum
  • Still works because good local minima → good performance

Tricks:

  • Good initialization
  • Learning rate tuning

Neural Networks as Feature Learners

Two-Step View:

Feature Learning: Hidden layers map Rᵈ → Rᵐ.

  1. Learn new features automatically
  2. Linear Prediction: Final layer applies linear model on features

Comparison with Kernel Methods

MethodFeature Mapping
Kernel MachinesPre-defined
Neural NetworksLearned from data

Key Insight: Neural networks learn both features and weights.

Specialized Architectures

  • CNN (Convolutional Neural Networks): Best for images. Detect edges, shapes, textures.
  • RNN / LSTM: Best for sequences (time series, speech, text).
  • Transformers: Modern architecture using attention mechanism. Best for NLP and complex tasks.

When to Use What

Data TypeBest Method

Final Intuition:
  • Neural networks = automatic feature learners
  • They replace manual feature engineering
  • Trade-off: lose easy optimization, gain high expressive power
One-Line Summary: Neural networks learn both features and predictions using high-dimensional parameters optimized via backpropagation, making them powerful for complex and unstructured data.

Lecture 6: Summary of the Course and Future Directions

A. Unsupervised Learning (No Labels)

1. Representation Learning

  • PCA (Principal Component Analysis): Projects data onto directions of maximum variance
  • Kernel PCA: Handles non-linear data using the kernel trick

2. Clustering

  • K-Means: Minimizes within-cluster distance
  • Spectral Clustering: Uses graph structure, works well for complex shapes

3. Estimation

  • Maximum Likelihood Estimation (MLE)
  • Bayesian Methods
  • Mixture Models + EM Algorithm:
    • E-step: Estimate hidden variables
    • M-step: Update parameters

B. Supervised Learning (With Labels)

1. Regression

  • Ordinary Least Squares: min Σ(yᵢ − Wᵀxᵢ)²
  • Regularized Regression:
    • Ridge Regression: Penalizes large weights. Σ(yᵢ − Wᵀxᵢ)² + λ‖W‖²
    • Lasso Regression: Produces sparse weights. Σ(yᵢ − Wᵀxᵢ)² + λ‖W‖₁

  • Semi-Supervised Learning: Mix of labeled and unlabeled data

Deployable AI / ML (Real-World Challenges)

1. Fairness

  • Problem: Models learn bias from data
  • Example: Crime prediction system biased due to historical data

2. Explainability (XAI)

  • Problem: Some models are black boxes
  • Easy to explain: Decision Trees
  • Hard to explain: Neural Networks
  • Examples:
    • Healthcare → doctor needs reasoning
    • Self-driving cars → accident accountability

3. Privacy

  • Problem: Models may leak sensitive data
  • Examples: Salary, medical records

4. AI for Edge Devices

  • Problem: Models too large
  • Solutions: Model compression, pruning, subsampling
  • Deployment: Phones, IoT devices

5. Continuous & Transfer Learning

  • Continuous Learning: Handle data drift (data changes over time)
  • Transfer Learning: Reuse knowledge from one task to another
  • Example: Cricket match prediction → player form changes, model must adapt continuously
